# Akili Afya

Akili Afya — Community Hub scaffold (mental health dimension). This is a vanilla JavaScript + HTML + CSS single-page app scaffold created with Vite.

Quick start

1. Install dependencies

   npm install

2. Run dev server

   npm run dev

3. Build for production

   npm run build

What’s included
- Simple hash-based router and pages: Home, Resources, Forum (mock), Quiz (self-assessment), Support, Profile
- Simple client-side mock store for forum posts (replace with a backend like Supabase or Firebase)
- Example data file for resources and quiz
- Supabase client stub at src/api/supabaseClient.js (fill SUPABASE_URL and SUPABASE_KEY as environment variables)

Deploying

I left the final step of putting this live to you. Recommended hosts: Vercel or Netlify. See docs/deployment.md for instructions.
